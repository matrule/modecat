# Instruments

ModeCat supports three instrument types plus an empty slot:

| Kind | Description |
|------|-------------|
| **Sample** | Plays a loaded WAV file. Supports loop points, transpose, finetune, and AHDSR envelope. |
| **Synth** | Generates audio from a 32-step single-cycle waveform with AHDSR envelope. |
| **MIDI** | Sends MIDI note-on/off to an external device via the bridge. |
| **Hybrid** | A sample instrument with a programmable pitch/volume program (like an Amiga synth). |
