# Pattern Entry

*This page is a work in progress.*

## Edit mode

Press `Return` to toggle edit mode. The EDIT indicator in the info bar shows the current state. Notes can only be entered when edit mode is on.

## Note keys

| Keys | Notes |
|------|-------|
| `Z S X D C V G B H N J M` | C through B in the lower octave |
| `Q 2 W 3 E R 5 T 6 Y 7 U` | C through B in the upper octave |
| `+` / `-` | Octave up / down |
| `F1`–`F5` | Set octave pair 1+2 through 5+6 |

## Cursor movement

| Key | Action |
|-----|--------|
| `↑ ↓ ← →` | Move one cell |
| `Tab` / `Shift+Tab` | Next / previous channel |
| `PgUp / PgDn` | Jump 16 rows |
| `Home / End` | First / last row |
| `F6`–`F10` | Jump to first / quarter / middle / three-quarter / last row |

## Cell fields

Each cell has four fields: **note**, **instrument**, **command**, **data**.

- Move left/right to switch between fields
- Instrument and command/data fields accept hex digits `0–9`, `A–F`
- `Del` or `Backspace` clears the current cell
