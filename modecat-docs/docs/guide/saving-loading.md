# Saving & Loading

## Save

Click **Save** in the save/load bar, or use the File menu. ModeCat downloads a `.modecat.json` file containing your full song — patterns, instruments (including PCM data encoded as base64), and transport settings.

## Load

Click **Load** and select a `.modecat.json` file. The current song is replaced.

::: warning
Loading a file replaces the current session. Save first if you want to keep your work.
:::

See [File Format](/advanced/file-format) for the full JSON schema.
