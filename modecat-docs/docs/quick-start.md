# Quick Start

## Run locally

```bash
git clone https://github.com/matrule/modecat.git
cd modecat
npm install
npm run dev
```

Then open [http://127.0.0.1:5173](http://127.0.0.1:5173).

## Your first sound

1. Click an instrument slot in the **Instrument List** on the right
2. In the **Sample Editor** below, click **Load WAV…** and pick a file
3. Press `Return` to enter edit mode (the EDIT indicator in the info bar turns on)
4. Move the cursor to row 00, channel 1 in the pattern grid
5. Press `A` — this enters a C-5 note using the selected instrument
6. Press `Space` to play

You should hear the sample play on every loop of the block.

## Basic navigation

| Key | Action |
|-----|--------|
| `↑ ↓ ← →` | Move cursor |
| `Space` | Play / stop |
| `Return` | Toggle edit mode |
| `+` / `-` | Octave up / down |
| `Del` | Clear cell |

See [Pattern Entry](/guide/pattern-entry) for the full keyboard reference.
